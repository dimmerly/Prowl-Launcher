# Introducing the Launcher

We now have a launcher for Prowl, as you probably know since you're seeing this :)

This launcher is meant to be a simple entry way to manage your Prowl editor version, play with the samples and quickly launch your projects.

Please be wary that that it's an still in early preview and will be improved over time. Please raise any issues on Github.

## Features

- Install and manage multiple Prowl editor versions, including previews.
- Add existing projects or create new ones from a blank project or template.
- Choose which editor version opens each project.
- Search projects, mark favourites, and see recently opened projects.
- Run sample scenes. After the first download, they work offline too.
- Read news and devlogs inside the launcher.
- Update the launcher with a changelog before installing.
- Language, theme, and display scaling settings.
- Windows, and preliminary macOS, and Linux support.
